# Salon Viyana Kandy

This project is a frontend-only prototype for a luxury bridal and beauty salon landing page.

## Files

- `index.html` – landing page structure
- `assets/css/style.css` – premium visual styling
- `assets/css/responsive.css` – responsive rules
- `assets/js/config.js` – all client-facing business configuration
- `assets/js/main.js` – interactions, nav, reveal animations, gallery lightbox
- `assets/images/` – demo image placeholders and portfolio assets

## Customize the business details

Update the values in `assets/js/config.js` to match the real salon information.

```js
const salonConfig = {
  name: "Salon Viyana Kandy",
  phone: "0777222336",
  whatsapp: "94777222336",
  address: "D.S. Senanayake Veediya, Kandy, Sri Lanka",
  instagram: "#",
  facebook: "#",
  email: "",
  businessHours: "08:00 AM – 05:30 PM",
};
```

## Notes

- No backend, booking, or payment flow is included.
- This is a frontend design prototype only.
- Replace placeholder images with real salon photography when available.

## Preview locally

Open `index.html` directly in a browser, or serve the folder with any local static server.
